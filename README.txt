LOTUS JANITORIAL WEBSITE (static HTML)

Pages
  index.html         Home page
  book-online.html   4-step Book Online flow
  contact.html       Contact page + quick quote
  assets/            Logo and photos (keep this folder next to the HTML files)

How to use
  Upload everything in this folder to your web host (public_html or similar).
  Open index.html in any browser to preview locally.
  Fonts (Poppins + Roboto) load from Google Fonts, so an internet connection is needed for the exact typography.

Notes
  - Booking and quote requests open the visitor's own text or email app pre-filled to
    (587) 777-2989 / info@lotusjanitorial.ca, with a Copy details fallback. Nothing is sent to a server.
  - To change phone, email, address, hours or copy, it is easiest to edit the source and re-export.
